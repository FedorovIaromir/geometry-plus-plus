# Changelog

Все заметные изменения в проекте **Geometry++** документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [2.0.0] — 2026-09-03

### Добавлено
- **Пространство имён `Geometry2D`** — все сущности библиотеки теперь находятся в нём
- **Новая структура `IntersectOut`**:
  - Теперь хранит `std::set<Point, CMPPOINT> P` вместо отдельных полей `P1`, `P2`
  - Компаратор `CMPPOINT` для упорядочивания точек в множестве
- **Операторы сравнения** для `IntersectOut` (`==`, `!=`)
- **Функции проверки вырожденности** для всех базовых типов:
  - `isDeg(Vector)`, `isDeg(Line)`, `isDeg(Segment)`, `isDeg(Circle)`
- **Операторы расстояний** между фигурами:
  - Прямая–Прямая (`>>`, `>`, `<`)
  - Прямая–Отрезок (`>>`, `>`, `<` и обратные)
  - Прямая–Окружность (`>>`, `>`, `<` и обратные)
  - Отрезок–Отрезок (`>>`, `>`, `<`)
  - Окружность–Отрезок (`>>`, `>`, `<` и обратные)
  - Окружность–Окружность (`>>`, `>`, `<`)
- **Операторы принадлежности**:
  - `Point | Triangle` — проверка, находится ли точка внутри треугольника
  - `Segment | Line` — проверка, лежит ли отрезок на прямой
- **Операторы пересечений с треугольниками**:
  - Проверка пересечения (`||`) для:
    - `Line` с `Triangle`
    - `Segment` с `Triangle`
    - `Circle` с `Triangle`
    - `Triangle` с `Triangle`
  - Вычисление точек пересечения (`&`) для:
    - `Line` с `Triangle`
    - `Segment` с `Triangle`
    - `Circle` с `Triangle`
    - `Triangle` с `Triangle`

### Изменено
- **Переход на явное использование `std::`** — убрано глобальное `using namespace std;`
- **Макрос `CHECKWARNINGS`** теперь использует `Geometry2D::SHOW_WARNINGS`
- **Вывод `IntersectOut`** теперь перебирает все точки из множества `P`
- **Оператор ввода `BaryCoords`**:
  - При неверной сумме координат теперь выдаёт предупреждение и устанавливает `BARYCENTER` вместо аварийного завершения программы
- **Функции `PaT2Bar` и `TaBar2P`** теперь используют `isDeg` и выводят предупреждение при вырожденном треугольнике
- **Все алгоритмы** (`std::sort`, `std::swap`, `std::min`, `std::max`) теперь вызываются с явным указанием пространства имён

### Удалено
- Поля `P1` и `P2` из структуры `IntersectOut` (заменены на множество `P`)

## [1.2.0] — 2026-08-31

### Добавлено
- **Система предупреждений**:
  - Макрос `CHECKWARNINGS` — условный вывод предупреждений
  - Глобальная переменная `SHOW_WARNINGS` (по умолчанию `true`) для управления предупреждениями
- **Новые функции проверки вырожденности**:
  - `isDeg(Vector a)` — проверка нулевого вектора
  - `isDeg(Line l)` — проверка вырожденной прямой
  - `isDeg(Segment a)` — проверка вырожденного отрезка
  - `isDeg(Circle o)` — проверка вырожденной окружности
- **Новая константа**:
  - `BARYCENTER` — барицентрические координаты центра тяжести `(1/3, 1/3, 1/3)`
- **Обработка вырожденных случаев** во всех функциях:
  - `normalize(Vector)` — возвращает `{0,0}` для нулевого вектора
  - `normalize(Line)` — возвращает `{0,0,0}` для вырожденной прямой
  - `project(Point, Line)` — возвращает исходную точку для вырожденной прямой
  - `project(Point, Segment)` — корректно обрабатывает вырожденный отрезок
  - Все функции треугольников теперь проверяют `isDeg` перед выполнением
  - Все операторы пересечений (`||` и `&`) корректно обрабатывают вырожденные фигуры

### Изменено
- **Константа `INF`** теперь использует `std::numeric_limits<double>::infinity()` вместо `1e500`
- **Оператор `<` для точек** теперь возвращает положительный квадрат расстояния (`lenS`) вместо отрицательного (`-lenS`)
- **Оператор вывода окружности** теперь использует строгое сравнение `>` вместо `>=` для проверки положительности координат
- **Функция `normalize(Line)`** теперь нормализует коэффициенты с учётом знака `C` (коэффициент `A` и `B` также меняют знак)

### Улучшено
- Добавлены предупреждения во все операторы ввода при обнаружении вырожденных фигур
- Добавлены предупреждения в конверторы (`P2V`, `P2L`, `P2S`, `V2S`, `S2V`, `S2L`, `V2L`, `P2T`, `P2C`, `PaT2Bar`, `TaBar2P`, `L2B`) при создании вырожденных объектов
- Функции `isAcute`, `isRight`, `isObtuse`, `isEquil`, `isIsosc`, `isScal`, `isSim`, `isCongr` для треугольников теперь проверяют вырожденность
- Функции `circumscribed`, `inscribed`, `inradius`, `circumradius` для треугольников теперь проверяют вырожденность
- Операторы расстояний между фигурами теперь корректно обрабатывают вырожденные случаи
- Все операторы пересечений теперь корректно обрабатывают вырожденные случаи

## [1.1.0] — 2026-08-28

### Добавлено
- **Барицентрические координаты**:
  - Структура `BaryCoords` для хранения координат (u, v, w)
  - Функция `PaT2Bar` — преобразование точки в барицентрические координаты
  - Функция `TaBar2P` — восстановление точки по барицентрическим координатам
  - Операторы сравнения `==` и `!=` для `BaryCoords`
  - Ввод/вывод для `BaryCoords` (с проверкой суммы)
- **Новые функции для треугольников**:
  - Проверки по сторонам: `isEquil`, `isIsosc`, `isScal`
  - Проверки подобия и равенства: `isSim`, `isCongr`
  - Приведение к обходу против часовой: `makeCCW`
  - Радиусы вписанной и описанной окружностей: `inradius`, `circumradius`
  - Длины высот: `lenHeiA`, `lenHeiB`, `lenHeiC`
  - Длины медиан: `lenMedA`, `lenMedB`, `lenMedC`
  - Длины биссектрис: `lenBisA`, `lenBisB`, `lenBisC`
  - Длины сторон: `lenAB`, `lenBC`, `lenAC`
- **Новые операторы расстояний**:
  - Между прямыми: `Line >> Line`, `Line > Line`, `Line < Line`
  - Между прямой и отрезком: `Line >> Segment`, `Line > Segment`, `Line < Segment` (и обратные)
  - Между прямой и окружностью: `Line >> Circle`, `Line > Circle`, `Line < Circle` (и обратные)
  - Между отрезками: `Segment >> Segment`, `Segment > Segment`, `Segment < Segment`
  - Между окружностью и отрезком: `Circle >> Segment`, `Circle > Segment`, `Circle < Segment` (и обратные)
  - Между окружностями: `Circle >> Circle`, `Circle > Circle`, `Circle < Circle`
- **Новые операторы принадлежности**:
  - `Segment | Line` — проверка, лежит ли отрезок на прямой
- **Пересечения с треугольниками**:
  - Операторы проверки пересечения `||` для:
    - `Line` с `Triangle`
    - `Segment` с `Triangle`
    - `Circle` с `Triangle`
    - `Triangle` с `Triangle`
  - Операторы вычисления точек пересечения `&` для:
    - `Line` с `Triangle`
    - `Segment` с `Triangle`
    - `Circle` с `Triangle`
    - `Triangle` с `Triangle`

### Изменено
- Защита заголовочного файла переименована с `GEOMETRY++_H_INCLUDED` на `GEOMETRYPLUSPLUS_H_INCLUDED`

### Удалено
- Функция `HELP()` (встроенная справка) — вместо неё рекомендуется использовать документацию

## [1.0.0] — 2026-08-24

### Добавлено
- Первая публичная версия библиотеки
- Базовые структуры: `Point`, `Vector`, `Line`, `Segment`, `BBox`, `Circle`, `Triangle`, `IntersectOut`
- Константы: `PI`, `INF`, `EPS`, `UNDEF`, `NAP`, `ZERP`, `INFP`
- Базовые математические функции: `iZ`, `iE`, `SQ`, `r2d`, `d2r`
- Функции для работы с векторами, точками, прямыми, отрезками, BBox, окружностями
- Функции для треугольников: площадь, углы, высоты, медианы, биссектрисы, средние линии, центры, описанная и вписанная окружности
- Перегруженные операторы: сравнения, арифметика, углы, расстояния (точка–фигура), принадлежность, пересечения (проверка и точка)
- Конверторы и BBox-конверторы
- Ввод/вывод для всех структур
- Полная документация в файле `Geometry++_Документация.docx`

## Формат версий

- **Major** (x.0.0) — несовместимые изменения API
- **Minor** (x.1.0) — добавление функционала (обратно совместимо)
- **Patch** (x.x.1) — исправление ошибок (обратно совместимо)
